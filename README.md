## О программе

**YtDlpGUI** — графическая оболочка для Windows, которая делает возможности `yt-dlp` доступными без необходимости вручную вводить команды в консоли.

Вставьте ссылку, выберите нужное качество или просканируйте доступные форматы, укажите папку и запустите загрузку.

Программа использует `yt-dlp` как движок загрузки и умеет автоматически подготовить необходимые компоненты для корректной работы с современными сайтами и форматами.

> YtDlpGUI является независимым графическим приложением и не является официальной частью проекта yt-dlp.

## Основные возможности

### Скачивание видео

- загрузка видео по URL;
- поддержка ссылок и плейлистов, обрабатываемых `yt-dlp`;
- выбор папки сохранения;
- отображение прогресса загрузки;
- журнал работы программы;
- отмена активной загрузки.

### Выбор качества

Доступен быстрый автоматический выбор:

- Лучшее доступное;
- 2160p / 4K;
- 1440p / 2K;
- 1080p / Full HD;
- 720p / HD;
- 480p;
- 360p.

Если указанное разрешение недоступно, `yt-dlp` выбирает подходящий доступный вариант.

### Сканирование и выбор точного формата

Начиная с версии **2.2.0**, YtDlpGUI умеет получать реальный список форматов для конкретного видео.

1. Вставьте URL.
2. Нажмите **«Сканировать форматы»**.
3. Дождитесь анализа.
4. Выберите конкретный вариант из списка.
5. Нажмите **«Скачать»**.

В списке могут отображаться:

- ID формата;
- контейнер: MP4, WEBM и другие;
- разрешение;
- FPS;
- видеокодек: H.264, VP9, AV1, H.265 и другие;
- размер файла, если он доступен;
- наличие встроенной аудиодорожки.

Если выбран формат только с видео, программа автоматически добавит лучшую доступную аудиодорожку и передаст объединение потоков FFmpeg.

### Только аудио

Можно переключиться в режим загрузки/конвертации аудио и выбрать формат:

- MP3;
- M4A;
- OPUS;
- WAV.

### Пакетная загрузка

YtDlpGUI поддерживает загрузку нескольких ссылок из текстового файла. Это удобно для серий роликов, подборок и других задач, где нужно обработать много URL подряд.

### Автоматическая подготовка компонентов

Кнопка **«Обновить компоненты»** позволяет установить или обновить рядом с программой:

- `yt-dlp.exe`;
- `deno.exe`;
- `ffmpeg.exe`;
- `ffprobe.exe`.

Deno используется как JavaScript runtime, а FFmpeg/FFprobe нужны для объединения потоков и обработки аудио/видео.

### Диагностика

При запуске приложение проверяет наличие компонентов и выводит состояние в журнал.

Также предусмотрена отдельная подсказка для ситуации, когда сайт возвращает **HTTP 403**.

### Сохранение настроек

Программа запоминает основные параметры между запусками:

- язык интерфейса;
- выбранное качество;
- аудиоформат;
- папку сохранения.

## Установка

### Готовая версия

1. Откройте раздел [Releases](https://github.com/wulkan-Git/YtDlpGUI/releases).
2. Выберите последнюю версию.
3. Скачайте готовый файл YtDlpGUI.
4. Запустите программу.
5. При необходимости нажмите **«Обновить компоненты»**.

Windows SmartScreen может показывать предупреждение для новых или неподписанных приложений. Проверяйте, что файл скачан именно из официального репозитория YtDlpGUI.

### Сборка из исходников

Требования:

- Windows;
- Visual Studio;
- .NET Framework 4.7.2.

Сборка:

```text
1. Открыть YtDlpGUI.sln
2. Выбрать конфигурацию Release
3. Build → Build Solution
4. Готовый файл: YtDlpGUI\bin\Release\YtDlpGUI.exe
```
