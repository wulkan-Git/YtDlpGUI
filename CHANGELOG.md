# Changelog

Все значимые изменения YtDlpGUI фиксируются в этом файле.

## [2.2.0] - 2026-08-19

### Новый дизайн

- Полностью переработан внешний вид программы.
- Добавлена фирменная тёмно-синяя цветовая схема.
- Добавлена градиентная синяя шапка с брендингом YtDlpGUI.
- Настройки, выбор формата, прогресс и журнал разделены на визуальные карточки.
- Поля ввода и выпадающие списки переведены на тёмную тему.
- Основные действия выделены ярким синим акцентом.
- Добавлена собственная синяя полоса прогресса.
- Переработаны цвета сообщений журнала.
- Оформление согласовано со стилистикой my.ws-soft.ru.

### Сканирование форматов

- Кнопка «Показать форматы» заменена на «Сканировать форматы».
- Для анализа используется структурированная информация `yt-dlp --dump-single-json`.
- Добавлен выбор конкретного формата после сканирования.
- Для форматов показываются ID, контейнер, разрешение, FPS, кодек, размер и наличие аудио.
- Выбранный точный формат имеет приоритет над автоматическим выбором качества.
- Для video-only форматов программа автоматически добавляет лучшее доступное аудио.
- После изменения URL результаты старого сканирования автоматически сбрасываются.
- Точный формат одного ролика не применяется к пакетной загрузке других URL.

### Загрузка и управление

- Сохранён автоматический выбор качества: Лучшее / 2160p / 1440p / 1080p / 720p / 480p / 360p.
- Сохранён режим «Только аудио» с MP3 / M4A / OPUS / WAV.
- Сохранена пакетная загрузка URL из TXT.
- Улучшено управление доступностью кнопок во время активных процессов.
- Улучшена работа кнопки отмены.

### Компоненты

- Автоматическая установка/обновление `yt-dlp.exe`.
- Поддержка Deno как JavaScript runtime.
- Автоматическая установка FFmpeg и FFprobe.
- Диагностика отсутствующих компонентов.
- Подсказка при HTTP 403.

### Локализация

Интерфейс и новые элементы доступны на шести языках:

- Русский;
- Беларуская;
- English;
- Deutsch;
- 简体中文;
- العربية (قطر), включая RTL.
